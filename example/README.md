# README

This folder contains a few examples of grain code. Without the extension installed the code blocks below and files in this folder should all have no syntax highlighting. Once the extension is installed there should be active syntax highlighting.

## Code Block Example

A basic block using the `gr` tag:
```gr
module Main

let test = () => print("test")
test()
```

block with `grain`:
```grain
module Test

enum Direction {
  North,
  South,
  East,
  West
}
```
